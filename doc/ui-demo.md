# Демонстрация веб-интерфейса

## Запуск

Из корня проекта, при установленном Docker с Compose:

```bash
docker compose up --build
```

Дождитесь готовности `app` и запуска `web`, затем откройте `http://localhost:8080/`. Если в `.env` задан `WEB_PORT`, используйте `http://localhost:<WEB_PORT>/` (порт по умолчанию — `${WEB_PORT:-8080}`). При первом старте Compose применяет миграции, загружает начальные справочники и создаёт демонстрационный набор. Отдельная команда подготовки данных не нужна. Для обычной остановки нажмите Ctrl+C; `docker compose down` сохраняет том БД. Повторный `docker compose up` сохраняет операции и прежнюю дату набора.

Дата в шапке «Дата снимка» приходит из `/api/demo/status`: при первом запуске на пустом томе это текущая дата Москвы, после перезапуска она не меняется. Контрольные числа ниже относятся к чистому набору на `2026-09-29`; при другой дате даты документов сдвигаются. На постоянно используемой БД результаты могут измениться после операций через публичный API.

## Маршрут показа

1. **Склад.** В таблице «Остатки по товарам и объектам» найдите `DEMO-OIL` на `DEMO-MS-01`. Учётный и доступный остатки на чистом снимке — `50.000`. Нажмите строку: раздел «Партии» показывает сроки, цены и документы прихода. Для `DEMO-EXPIRED` на `DEMO-MS-01` учётный остаток — `10.000`, доступный — `0.000`. В «Журнале движений» задайте SKU, нажмите «Применить фильтры», откройте следующую страницу кнопкой «Далее →» и проверьте распределения расхода по партиям и отметку FEFO.
2. **Риски.** Перейдите по «Риски и прогноз» к таблице «Предупреждения». Найдите дефицит `DEMO-DEFICIT` и риск срока годности `DEMO-EXPIRY`; раскройте «Исходные показатели» у предупреждения.
3. **Прогноз.** В том же разделе просмотрите «Прогноз выбранной пары» для `DEMO-OIL` и `DEMO-MS-01`. Пара меняется выбором строки склада. Проверьте остаток, средний расход, поставки в пути, страховой запас, точку заказа, рекомендуемое количество, стоимость и даты. Раскройте объяснение с исходными данными, формулами, допущениями и дневным прогнозом.
4. **План закупок.** Перейдите в «План и бюджет». По умолчанию выбран горизонт «3 месяца»; на чистом снимке `2026-09-29` позиция `DEMO-OIL`/`DEMO-MS-01` содержит `30.000` и `3000.00 ₽`. Смените горизонт на «1 месяц»: расчёт запустится сразу. Измените объект, категорию, страховой запас или лимит и нажмите «Пересчитать»; проверьте применённые параметры, период, позиции и существующие заказы.
5. **Бюджет.** В результате того же плана просмотрите известную часть суммы и разрезы по месяцам, товарам, категориям и объектам. Если цена или стоимость позиции неизвестна, интерфейс показывает «Нет данных» и признак неполного бюджета: известная сумма не является полной стоимостью. Недатированные позиции показаны отдельно; их нельзя считать заказами с известной датой. Проверьте статус лимита, предупреждения и объяснение расчёта.
6. **Движение `OIL-001`.** Перейдите в «Операция» → «Провести движение». Для предзаполненных `OIL-001`/`MS-01` выберите «Приход»: укажите дату операции, `2.000`, новый уникальный номер документа, номер партии и цену `100.00 ₽`; срок годности можно оставить пустым. Нажмите «Провести движение». В результате должны появиться ID, учётный и доступный остатки; склад и журнал обновляются. Затем выберите «Расход», укажите `1.000` и другой новый номер документа. Результат показывает распределения по партиям, а остаток уменьшается на `1.000`.

## Ручная проверка в браузере

- Обновите страницу и убедитесь, что дата снимка и данные загружаются без входа; ссылки навигации ведут к нужным разделам. Блок «AI-помощник — в разработке» не содержит работающего чата.
- Проверьте фильтр и вторую страницу журнала, раскрытие показателей риска и формул прогноза, пересчёт `3 → 1` месяц, неизвестную цену и позицию без даты заказа. После пересчёта старый ответ не должен заменять новый.
- В форме введите `DEMO-OIL`: кнопка отправки блокируется и показывается причина. Верните `OIL-001`, проведите приход и расход из маршрута выше; проверьте новые записи и остаток. Повторите номер уже проведённого документа: форма должна показать ошибку `HTTP 409`, а не сообщение об успешной операции.
- Если раздел сообщает об ошибке загрузки, используйте расположенную рядом кнопку «Повторить». Страница API доступна по ссылке «API» (`/docs`).

Форма защищает `DEMO-` только в браузере; прямой вызов API этим правилом не ограничен. Для повторения контрольных чисел нужен чистый демонстрационный набор.
