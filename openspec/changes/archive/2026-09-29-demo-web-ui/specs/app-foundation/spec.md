# Spec Delta

## ADDED Requirements

### Requirement: Единый запуск веб-демонстрации
Команда `docker compose up` SHALL запускать PostgreSQL, backend и отдельный веб-сервис без дополнительных ручных команд подготовки демоданных. Веб-сервис SHALL обслуживать сайт и передавать запросы к действующему backend через тот же адрес. Он SHALL становиться доступным для проверки после готовности backend; при сбое подготовки данных SHALL показывать ошибку, а не ложный успешный расчёт.

#### Scenario: Первый запуск на пустом томе
- **WHEN** пользователь запускает `docker compose up` с пустым томом БД
- **THEN** после миграций и загрузки данных доступны сайт, API и `GET /health`, а сайт показывает склад, риски и план.

#### Scenario: Повторный запуск
- **WHEN** контейнеры остановлены и запущены вновь без удаления тома
- **THEN** сайт доступен, ранее проведённые операции удалены, а сиды и демонабор восстановлены на текущую дату Москвы.
